
### 配置DeepSeek API
1. 环境变量方式：
   ```bash
   set DEEPSEEK_API_KEY=your_key_here
   ```

2. 配置文件方式：
   ```bash
   cd backend/services
   cp deepseek_config.json.example deepseek_config.json
   # 编辑 deepseek_config.json 填入API密钥
   ```
