## 📋 项目概览

**温蒂的翻译助手** 是一个专为小学生设计的个性化英语学习应用，采用前后端分离架构，提供友好的用户体验和强大的学习功能。

### 核心功能
- 🔄 **智能翻译** - 英中文本互译，支持多种输入方式
- 🤖 **AI对话助手** - 集成DeepSeek AI，提供智能问答和学习辅导
- 📚 **单词本管理** - 保存、复习、掌握程度跟踪
- 📊 **学习进度** - 详细的学习统计和里程碑
- 🏆 **成就系统** - 激励学习的徽章和奖励
- 🎨 **个性化界面** - 多主题、头像、语言切换
